# Sprint 3.1 — lateral interflow on equal z

**Status:** ready for oracle
**Depends on:** S03 green on main
**Out of scope:** plants, ET, Richards PDE, editing docs/.

## Why

S03 only drained to *strictly lower z*. Two valley cells at the same elevation never shared gravity water, so a wet sand bench stayed wet next to dry loam.

## Physics (locked)

Mobile soil water is m = (θ − θ_fc)+ · L. Capillary water (θ ≤ θ_fc) still does not move.

Gravity-drain pass (after infiltrate + S02.1 pond runoff):

1. Candidates: 4-neighbors with z_nbr < z_i, or z_nbr == z_i and m_nbr < m_i.
2. Never send to z_nbr > z_i.
3. If any candidate has strictly lower z, send only among those (lowest z; NESW if that z ties). Volume V = min(D_max, m_i). Split equally. Add to neighbor **surface** (same as S03).
4. Else (flat bench only): for each equal-z neighbor with m_nbr < m_i, send
   V = min(D_max_share, 0.5 * (m_i − m_nbr))
   where D_max_share is this cell's D_max split across those neighbors (or cap each send by D_max total leaving the cell this pass — total leaving ≤ D_max).
   Add V to the neighbor's **soil** θ (not surface) so a flat bench equalizes in the dirt without a fake puddle. If adding would exceed φ, leftover goes to that neighbor's surface.

Simultaneous snapshot of z, θ, m; then apply deltas.

Pond routing unchanged (S02.1).
