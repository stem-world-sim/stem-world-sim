# Sprint 14.1 — Catch-up advances height_frac

**Status:** locked for oracle  
**Depends on:** S14 growth clock; S09 / S09.1 catch_up.

## Goal

`height_frac` uses the same clock as water and wilt: live ticks when visited, the same Δ on each catch_up tick-equivalent when ignored.

S14 RUNLOG: catch_up does not advance height_frac. Close that. No second growth model.

## Rule

On each catch_up tick-equivalent for a living occupant on the work set:

height_frac = min(1, height_frac + Δ0 * f_L * f_w * f_T)

Same Δ0, f_L, f_w, f_T, H0, clamp as S14.

L / θ / T for the block: reuse catch_up period aggregates (S09.1). One light walk at block start if no L yet; hold for the block. Wilted => f_w=0.

Ignore with zero catch_up still freezes height.

plant_taxon remains mature. No species if. No docs/ edits.
