# Sprint 19.2 — page and pond

**Status:** locked for oracle
**Depends on:** S19.1 (`c157db8`).

The page still speaks the old counters, and a waterlogged rice loses water. The rice is a bug, not a design choice.

## Design

A plant with `takes_dissolved` keeps root O2 open when waterlogged. It takes soil water. Rice is that plant. If a planted rice has `takes_dissolved` false, that is the bug. If the flag is set and uptake is still zero, that is also the bug.

The water store recharges from soil extraction. While a pond is present and root O2 is open, the store must not fall. A plant standing in water with open roots does not dry out.

## Page

- Drop the five old counters from the plant card and the reason line: dry, dark, waterlogged, submerged, crowded. Death is an empty store. The reason names the falling store (`water falling`).
- Condition flags in plain ASCII: `L ok`, `CO2 no`, `root O2 no`, `T ok`. No check mark, no cross, no arrow. Those glyphs render as empty boxes on a phone.
- Event log stamps elapsed days (`173.0 d`), not a step count.
- Key lists store ids and the four condition words. No counter thresholds.

## Tests

- `d192_pine_does_not` — same tile, a pine. Root O2 is closed. Soil uptake is zero.
