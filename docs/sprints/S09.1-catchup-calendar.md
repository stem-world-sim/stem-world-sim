**Status:** ready for oracle

## Bug

S08 catch_up was: add rain → hydro until rest → then K sinks.
That finishes percolation before any plant drinks. Shallow roots see a dry top and wilt. Live ticks interleave hydro and sinks, so the plant sips the top while water is still moving.

## New rule

`catch_up` / `catch_up_chunk`:

```
optional: h += K * rain_per_step   # still one dump if R>0
for s in 1..=K:
    for t in 1..=N_ET:
        hydro_step()               # awake cells only
        if awake_count()==0: break
    one sink-step                  # ET then occupants
clock += K * N_ET
```

Do **not** hydro-to-rest before the first sink.

Ignore may be applied while moving. Come-back catch_up owns the unfinished cascade.
`d8_drought_matches_live_sinks` still holds when already at rest (inner hydro loop is 0).
