# Sprint 4.1 — lake snap

**Status:** ready for oracle
**Depends on:** S04 green
**Out of scope:** plants, ET, editing docs/.

## Physics

A connected free surface at rest has one head H*. Discrete slosh toward H* is an artifact. Snapping to H* with sum h conserved is the hydrostatic end state, not a different law.

Soil lateral into a column at φ is also an artifact (equal-m across different textures). Flux ≤ unused pore room. If room = 0, V_soil = 0. Extra water is already pond.

## Rules

1. Soil percolate / lateral: V = min(old cap, unused pores on the receiving layer). If unused = 0, V = 0. Do not convert that blocked volume into pond inside the soil pass (pond already exists or will form from infiltrate leftover).
2. After infiltrate + pond + soil: find 4-connected components where every member has h > V_rest and every intra-edge has |ΔH| ≤ H_rest (0.02). For each such component with N≥2, or N=1 sitting on soil that has no unused pores and no mobile that can leave to a lower-z cell:
   - H* = (Σ h_i + Σ z_i) / N
   - set h_i = max(0, H* − z_i)
   - Σ h unchanged (A=1).
   - mark those cells at_rest.
3. Keep S04 sleep. Snap does not create or destroy mass.
