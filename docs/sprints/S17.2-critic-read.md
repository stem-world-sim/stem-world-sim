# Sprint 17.2 — critic can be read

**Status:** locked for oracle
**Depends on:** S17.1.
**Does not change:** seed pulse, MAX_OCCUPANTS, layer rule, herb bands, uptake, wilt, ci.yml.

## Problem

The page does not fit a phone. Buttons show scientific names. A mature loblolly pine fills the tile with seedlings and then every plant dies, and the page does not say why.

## What the pine run is

A mature `pinus_taeda` is fertile (`height_frac` ≥ 0.5). Seed rain places one seedling per fertile plant per tick. Wind may land on the same tile. The cap is 8, so the tile fills in 7 ticks.

The critic tile starts at field capacity and gets no rain. Each living plant takes `P_MAX` (0.01 m) per tick. Eight plants empty the column in a few ticks. `T_WILT` is 3 dry steps, then `alive` is false. That is the death. Do not change it. Show it.

## Deliver

Same `crates/critic`. No new crate. No physics in the UI.

Layout:

- Narrow width (phone): stack controls, wrap plant buttons, larger tap targets, no horizontal scroll for the plant list.
- Wide width: the current row layout is fine.
- Use the window width. Do not hard-code a phone.

Names:

- Catalog column `common_name` is on `docs/data/kernel_catalog.csv`. Read it.
- Button and row label: common name, scientific in parentheses. Example: `Loblolly pine (Pinus taeda)`.
- Missing common name: scientific only.

Telemetry, from the kernel only:

- Tile: tick, living/cap, pond m, each layer θ and θ_fc.
- Each plant: name, height_m, height_frac, layer, A, over, light, alive.
- Stress counters the kernel already has: dry_steps, dark_steps, waterlog_steps, submerge_steps, crowd_steps, and the threshold each counts toward (`T_WILT`, `T_DARK`, `T_WL`, `T_SUB`, `T_CROWD`).
- One reason line per plant, plain words. Examples: `ok`, `dry 2/3`, `dark 4/7`, `crowded 6/7`, `wilted: soil dry`.
- A short event line when something changes: seed placed, wilted, thinned, removed. Last few events visible.

Key:

- A panel that defines every symbol on the page: A, over, layer, h_frac, θ, θ_fc, pond, the T_* counters, living/cap.
- Always visible or one tap away. Not a comment in code.

A rain control that calls the existing kernel rain path is allowed, so a critic can tell drought from other deaths. It must not invent a new sink or source.

Page: after green, rebuild `critic.html.gz` and replace the `critic` release asset. Do not commit `dist/`. Do not edit `ci.yml`.
