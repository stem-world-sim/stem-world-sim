# Sprint 3.2 — profile first, then lateral

**Status:** ready for oracle
**Depends on:** S03.1 green on main
**Out of scope:** plants, ET, Richards PDE, editing docs/.

## Why

S03 drained mobile θ sideways even when the same column still had empty pores below. A wet cap over dry subsoil leaked like a perched table. Downslope flux also skipped the neighbor's soil and appeared as a pond. Sand could push its full D_max into clay.

## Tick order (replaces S03 drain-only step; infiltrate + S02.1 pond unchanged)

1. Rate-limited infiltrate (S03).
2. S02.1 pond runoff.
3. **Percolate** each column, top → bottom: mobile water in layer k may fill remaining pore in layers k+1, k+2, …. Volume this tick ≤ that column's D_max (use the source layer's texture D_max; if layers share one texture, one budget). Do not pull below θ_fc. Simultaneous within the column (snapshot θ, then apply).
4. **Lateral / downhill** on leftover mobile m after percolate:
   - Same candidate rules as S03.1 (no uphill; lower z wins over equal z).
   - Contact cap: flux from i to j ≤ min(D_max_i, D_max_j) and ≤ leftover m_i. Equal-z still uses half-difference of leftover m, also ≤ that contact cap.
   - Receiver: add to **soil** top-down (same as infiltrate fill). Overflow past φ becomes surface pond.
   - Downslope no longer dumps straight onto surface if the neighbor still has pore space.

Capillary θ ≤ θ_fc still does not move.

## Deliverables

1. Percolate pass + drain pass as above. Keep S03.1 tests green (they must still pass; downhill-to-surface-only is no longer the path if pores remain).
2. New ACCEPTANCE names in the S03.2 section.
3. oracle/RUNLOG.md for S03.2.
4. Do not edit docs/.

## Note on d3_hill / d31 tests

Existing scripts still require mass downhill and no uphill. They must not assume the first downhill increment is 100% surface. Query column M and θ, not only h_surf, for "valley gained water." If an old test asserts surface-only arrival and that contradicts this spec, implement the new physics and add the S03.2 names; do not weaken I1–I6.
