# Sprint 16.3 — canopy layers by height

**Status:** locked for oracle
**Depends on:** S16.2 canopy bucket.
**Does not change:** seed pulse. S16.1 is skipped. Seed is still once per tick.

## Problem

S16.2 puts every tree and shrub on a tile in one bucket. A 13 m pine and an 8.6 m pine share A and start the crowd clock. That is lateral crowding applied to a vertical stack. Light already shades the shorter stem. The bucket should only compete crowns in the same layer.

## Rule

Herbs stay on 5 cm bands.

form=tree and form=shrub on a tile are grouped into layers. Two living woody occupants are in the same layer when

|h_i - h_j| <= max(1 m, 0.25 * max(h_i, h_j))

Transitive. Each layer has its own A_L = sum alpha * height_frac^2.
If A_L > 1, members of that layer get s = 1/A_L on alpha_eff and uptake, and the crowd counter advances. At T_CROWD=7, drop the weakest in that layer (lowest f_L * f_w * f_T * height_frac). A stem in a lower layer does not join that sum and is not removed by it.

13.1 m and 13.0 m share. 13.1 m and 8.6 m do not (gap 4.5 m, threshold 3.3 m). A seedling under a mature pine does not join the mature layer. No RNG. No English-name branch. Catch_up uses the same layers. Light walk is unchanged.
