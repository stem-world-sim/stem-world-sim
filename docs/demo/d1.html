D1 — 3×3 grid runoff

Same rule as sim-core: infiltrate every cell, then one simultaneous surface pass. Neighbors are N, E, S, W. Download this file and open it locally.

Ridge = high elevation wall (z = 12) on the west. Water does not climb it. Click a cell, add rain, then press One tick — rain itself does not move water.

N ↑ y increases north
W ← x → E

Fill = pond depth h. Arrow = where that cell sent water last tick. Green border = selected.
